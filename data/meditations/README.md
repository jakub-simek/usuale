# Meditations

Dieser Ordner enthält eigene liturgische Meditationen.

## Struktur

- Direkt in `data/meditations/` liegen Meditationen, die einer konkreten Feier oder einem konkreten liturgischen Text zugeordnet sind.
- `topics/` enthält Meditationen, die thematisch angelegt sind und nicht primär an eine einzelne `celebratio` gebunden sind.

Thematische Meditationen sollten in der YAML-Kopfzeile `scope: thematic`,
`topic`, `lang`, `status` und nach Möglichkeit `related_study` oder
`related_celebrations` angeben.
